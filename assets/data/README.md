# Official food catalog assets

`nutrikuaa_foods.db` will be generated by
`tools/food_importer/import_usda.py` and reviewed before being committed to a
release.

The application must never build this database by scraping or downloading
FoodData Central during installation.

`food_db_manifest.json` identifies the bundled catalog version. A future app
release may replace the official catalog when its `dataVersion` changes.

Professional/user data is stored separately and must never be overwritten by
a catalog update.
